# List available CMHC surveys

List available CMHC surveys

## Usage

``` r
list_cmhc_surveys()
```

## Value

A data frame with available survey names.

## Examples

``` r
list_cmhc_surveys()
#> # A tibble: 6 × 1
#>   Survey           
#>   <chr>            
#> 1 Scss             
#> 2 Rms              
#> 3 Srms             
#> 4 Seniors          
#> 5 Census           
#> 6 Core Housing Need
```
